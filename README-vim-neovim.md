# Vim keybindings

## Navigations

```
h,j,k,l
ctrl+f
ctrl+b
```


Browse Directory:

```
:E /path/of/directory
```

Create splits:

```
Horizontal split
:split
```

```
Vertical split
:vsplit 
```

Navigate Splits:

```
Ctrl+w -> (h,j,k,l or arrow keys) 

Close all but current buffer
Ctrl+w -> o
```

Exit from Terminal mode:

```
Ctrl+/ -> Ctrl+n
```
