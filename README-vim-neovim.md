## Operations

Deleting
```
x
X
operation{motion}

dh
dl
dj
dk
d0
d$

3dd
5dw
```



Browse Directory:

```
:E /path/of/directory
```

Create splits:

```
Horizontal split
:split
```

```
Vertical split
:vsplit 
```

Navigate Splits:

```
Ctrl+w -> (h,j,k,l or arrow keys) 

Close all but current buffer
Ctrl+w -> o
```

Exit from Terminal mode:

```
Ctrl+/ -> Ctrl+n
```
